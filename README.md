# Achadinhos da Shopee — Landing Page

Landing page criada para divulgar o grupo gratuito "Achadinhos da Shopee" no Telegram, onde são compartilhadas diariamente ofertas, cupons e produtos com desconto da Shopee.

O objetivo da página é converter visitantes em membros do grupo, usando elementos como:

- **Barra de urgência** com contador regressivo, reforçando que as ofertas do dia são por tempo limitado;
- **Prova social**, exibindo o número de pessoas que já fazem parte do grupo;
- **Simulação de chat**, mostrando como são as mensagens de oferta enviadas no Telegram;
- **Vitrine de ofertas** com exemplos de produtos, descontos, progresso de vendas e quantidade vendida;
- **Benefícios** de entrar no grupo (cupons antes de esgotar, produtos testados, sem spam);
- **Como funciona**, explicando o passo a passo para entrar e aproveitar as promoções;
- **FAQ**, respondendo dúvidas comuns sobre o grupo;
- **CTA fixo (sticky)**, mantendo o botão de entrada sempre visível durante a navegação.

O projeto é independente e não possui vínculo oficial com a Shopee — serve apenas como canal de divulgação de ofertas.

## Tecnologias

- HTML5 semântico
- CSS3 (sem frameworks)
- JavaScript puro (apenas para os contadores regressivos)

## Como usar

Basta abrir o arquivo `index.html` em um navegador. Não há build nem dependências.
